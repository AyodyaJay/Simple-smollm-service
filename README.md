# Simple-smollm-service
Custom service wrapping simple Open AI model

A simple custom REST API wrapping the open-weight
`HuggingFaceTB/SmolLM-135M-Instruct` model using FastAPI.

## Files

```text
simple_smollm_service/
├── app.py
├── requirements.txt
└── README.md
```

## Run on Windows

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Then open:

```text
http://localhost:8000/docs
```

## Test

Use `POST /generate` and enter:

```json
{
  "text": "Explain artificial intelligence in simple words."
}
```

The service returns the response generated by SmolLM2.

## Architecture

```text
User
  ↓
FastAPI
  ↓
/generate
  ↓
SmolLM-135M-Instruct
  ↓
Response
```

This demonstrates a custom REST service wrapping an open-weight model.

No GPU is required; CPU execution is supported.

Check the model repository for its current license and usage terms.
